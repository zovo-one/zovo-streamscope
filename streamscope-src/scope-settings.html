Local data

Browser-session storage

Current tab inventory, page-player state, and prior URLs live in chrome.storage.session. Chrome removes them when the browser session ends.

Permissions

Why broad page access?

  • webRequestReads URL and response headers for passive type and size hints.
  • tabs & webNavigationKeeps each inventory attached to the correct tab and page visit.
  • storageRestores the inventory if the MV3 worker sleeps.
  • clipboardWriteCopies the exact observed URL when you click Copy URL.
